SEASONAL AGRICULTURE PERFORMANCE ANALYSIS
===========================================

Submission package:
1. Seasonal_Agriculture_Performance_Analysis.ipynb
   - Complete Jupyter Notebook analysis
2. seasonal_agriculture_performance_cleaned.csv
   - Cleaned dataset used for analysis
3. Seasonal_Agriculture_Project_Report.docx
   - Project report
4. 01_average_yield_by_season.png
5. 02_average_profit_by_crop.png
6. 03_seasonal_rainfall_water_use.png
7. 04_water_efficiency_by_season.png
8. 05_correlation_heatmap.png

How to use:
- Put the notebook and cleaned CSV in the same folder.
- Open the notebook in Jupyter Notebook or Google Colab.
- Run all cells.
- Use the generated charts as screenshots for the PPT RESULTS slides.
- Fill in your name, roll number and college details in the report/PPT.

Important:
The analysis is based only on the supplied dataset. Correlation indicates association and does not prove causation.
