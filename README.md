# Seasonal Agriculture Performance Analysis

## Major Project – VOIS AICTE Batch 1 2026–2027

### 📌 Project Overview

This project analyzes agricultural data across different seasons to identify patterns, trends, relationships and differences in agricultural performance.

The analysis focuses on crop yield, profitability, environmental conditions, resource usage and irrigation.

### 🎯 Objectives

- Explore and understand the agricultural dataset
- Clean and prepare the data
- Compare agricultural performance across seasons
- Identify seasonal patterns and trends
- Analyze relationships between environmental conditions and agricultural outcomes
- Compare crop and irrigation performance
- Apply statistical and visualization techniques
- Develop evidence-based conclusions and recommendations

### 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

### 📊 Dataset

The dataset contains agricultural records covering:

- Seasons
- Crops
- States and districts
- Environmental conditions
- Soil conditions
- Irrigation
- Fertilizer and pesticide usage
- Production
- Yield
- Revenue
- Cost
- Profit
- Water usage
- Disease/Pest risk

### 📈 Key Findings

- Kharif recorded the highest average yield among the three seasons.
- Kharif recorded the highest average profit.
- Zaid recorded the lowest average yield.
- Zaid had negative average profit in the analyzed dataset.
- Sugarcane showed the highest average yield and average profit among the analyzed crops.
- Water efficiency varied across seasons.
- Profit showed strong relationships with revenue and moderate relationships with production and yield.
